# 当前阶段建议先做的核心模块

现阶段建议只围绕 **最小可运行版本 MVP** 做闭环：

```text
游客登录
  ↓
大厅
  ↓
匹配
  ↓
房间
  ↓
Game Server / Tick
  ↓
移动同步
  ↓
食物吞噬
  ↓
玩家吞噬
  ↓
局内排行榜
  ↓
结算
  ↓
战绩
  ↓
返回大厅
```

也就是先实现这些模块：

| 优先级 | 模块               |
| ------ | ------------------ |
| P0     | 用户游客登录       |
| P0     | 大厅               |
| P0     | 匹配系统           |
| P0     | 房间系统           |
| P0     | Game Server / Tick |
| P0     | WebSocket 通信     |
| P0     | 状态同步           |
| P0     | 基础移动           |
| P0     | 食物系统           |
| P0     | 基础碰撞与吞噬     |
| P0     | 局内排行榜         |
| P0     | 结算系统           |
| P0     | 战绩系统           |
| P1     | 断线重连           |
| P1     | 用户资产           |
| P1     | 全服排行榜         |
| P1     | 任务与成就         |

------

# 阶段划分建议

## MVP 阶段：先做核心对战闭环

目标：

```text
能登录 → 能匹配 → 能进房 → 能多人移动 → 能吞噬 → 能排行 → 能结算 → 能看战绩
```

## V1 阶段：增强稳定性和体验

加入：

```text
断线重连
用户资产
全服排行榜
任务与成就
AOI 优化
Protobuf 协议
基础监控
```

## V2 阶段：增强长期留存

加入：

```text
皮肤
商城
等级奖励
活动
邮件
个人主页
好友排行榜
```

## V3 阶段：增强竞技和运营

加入：

```text
排位
赛季
段位
组队
观战
回放
反作弊
运营后台
榜单奖励
```

当前最重要的是别贪多。先把 **“一局游戏从开始到结束”** 做完整，后面的系统才有接入价值。
